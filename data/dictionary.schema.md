# dictionary.json — Data Contract

Generated by Python pipeline (`dictionary.py`), consumed by Vue `WordPopup.vue`.

## Schema

```json
{
  "bookId": "string — matches chapters.json",
  "words": {
    "<lemma>": {
      "lemma": "string — base form",
      "phonetic": "string — pronunciation (MW format or empty)",
      "partOfSpeech": "string — e.g. 'noun', 'verb', 'adjective'",
      "definitions": ["string — up to 5 short definitions"],
      "audioUrl": "string — MW pronunciation MP3 URL (or empty)",
      "level": "string | null — 'SAT', 'AP', or null",
      "chapters": ["string — chapter IDs where this word appears"],
      "surfaces": ["string — 正文里映射到该词头的全部表面形（小写去重、含自身）"]
    }
  }
}
```

## 键口径（2026-10-04 · 0.3）

- 键 = **词头**（ECDICT `exchange` 的 `0:` 字段优先，手写规则兜底）；正文里的屈折形进该词条的 `surfaces`，前端靠 `reader/src/utils/dictIndex.js` 反查。
- **连字符复合词整体入键**（`well-known` / `after-dinner`）；ECDICT 没有这条时（`low-roofed`）退回拆词口径，复合词里的实词照常进候选。
- **NGSL 例外**：`clothes` / `ground` 以自身为词头、不参与 NGSL 过滤（ECDICT 会把它们并到语义不同的 `clothe` / `grind` 上）。
- 生成 / 重生成：`generator/rebuild_dictionary.py <bookId> [...]` —— 复用生成链同一份口径，旧键与已有释义一律保留。
- 例外：`sat-practice`（词表由 `build_sat_bank.py` 产）与 `500`（292 章扫描图）不走这条正文分词口径。
