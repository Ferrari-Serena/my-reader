# Third-party data and code

`public/dict-zh/` is generated by `tools/build-zh-dict.mjs` from the
`packs/en-zh-Hans` pack of **ChanMo/LexiBridge**, whose dictionary entries come
from **ECDICT**. Both are MIT-licensed. `src/utils/zhDict.js` and the build tool
adapt LexiBridge's word-matching and definition-parsing code.

No CEFR-J levels are used: only `dict.json` is consumed, not `levels.json`.

## Modifications

- Selected 34,730 entries from the pack; keys normalised to lowercase.
- Split into 26 first-letter shards; values reduced to
  `{p, t}` = phonetic, POS-prefixed Chinese definitions. The word is the shard
  key; `w` is omitted because it always equals the key.
- Definitions parsed with LexiBridge's `parseDefinition()` into
  POS-prefixed sense strings; no example sentences or audio.
- Irregular-verb table filtered to forms whose base exists in the shard set,
  emitted as `public/dict-zh/irregular.json`.
